JPG、PNG 和 HEIC 的区别

格式画质大小适合
JPG / JPEG很好（有损）小微信、QQ、社交媒体、邮件、网页，哪里都能打开
PNG无损最大修图、带文字的封面、拼图
HEIC非常好同画质下最小Apple 照片图库、iPhone 与 Mac 之间

拿不准？发送用 JPG，编辑用 PNG。

为什么不用在线转换

  • 要上传整段视频：用流量很慢，也不适合私人视频。
  • 很多网站按固定间隔截取：几百张图，却可能没有你要的瞬间。
  • 免费版常有大小限制或水印。

在 iPhone 上把视频帧转成 JPG、PNG 或 HEIC

  1. 打开视频

    从“照片”共享到 Video To Photo – Grab Frame，或在 App 中选择视频。

  2. 保存帧

    在每个瞬间轻点保存，只有选中的帧会被转换。

  3. 选择 JPEG、PNG 或 HEIC

    轻点“导出”，在顶部选择图片格式。

  4. 存为文件、ZIP 或 PDF

    导出为单张图片、ZIP 或 PDF，存到“照片”或“文件”，或直接分享。

用你自己的视频试试，只需一分钟。

不同用途选什么格式

  • 视频封面、抖音或 B 站封面 → PNG，再加文字。见用视频制作封面。
  • 发到 Windows 或安卓 → JPG（HEIC 不是到处都能打开）。
  • 打印 → 4K 视频导出的 PNG 或高质量 JPG。
  • 归档大量帧 → HEIC 打包成 ZIP。
  • 放进文档 → PDF，见视频转 PDF。

转换会降低画质吗？

PNG 保留帧的每一个像素。JPG 和 HEIC 会压缩，但在照片级质量下几乎看不出差别。比格式重要得多的是：从文件导出，而不是截屏。

常见问题

iPhone 能免费把视频转成 JPG 吗？

Video To Photo – Grab Frame 可免费下载，Pro 功能为 App 内购买。帧在 iPhone 上转换，视频不会被上传。

能把视频帧存为 PNG 吗？

可以。保存帧后，导出时选择 PNG，存为单独文件或 ZIP。

Windows 能打开 HEIC 吗？

新版 Windows 装上扩展后可以，但不是所有电脑都行。发给非 Apple 设备时，JPG 更稳妥。
